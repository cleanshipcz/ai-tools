# Waived review findings — user-scope deployments

Decisions by team-lead, iteration 1 of the review loop. Full findings in `reviewer-code-user-scope-deployments.md` and `reviewer-security-user-scope-deployments.md`.

- **SEC-4 (MAJOR)** — project-scope `prepare()` deletes the tool directory wholesale and `deploy.directory: ${HOME_FOLDER}` + `replace: true` would erase `~/.claude`. WAIVED for this branch per reviewer-security's own verdict: pre-existing project-scope behavior, not introduced by this diff, no manifest on this machine points at a home root. Recorded as a follow-up in `PLANNED_FEATURES.md` during the documentation step (guard `deploy.directory` against home/`/`/tool roots; make `prepare()` delete only owned artifact paths).
- **SEC-7 (MINOR)** — an omitted filter block selects everything, which in user scope flattens every ruleset into `~/.claude/CLAUDE.md`. WAIVED: the permissive default is the spec's explicit choice ("same semantics as ProjectDeploy.tools", filter blocks reuse project semantics); changing it is a schema deviation this delivery may not make. The shipped `globals/user.yml` already declares explicit filters with a comment. The provenance-marker idea (name the source manifest per ruleset block) is recorded as a follow-up.
- **SEC-3, opt-in-flag portion only** — requiring a `--user-scope` flag before any user deployment runs. WAIVED as a spec deviation: the design says user deployments load and export like every other kind. The two in-scope mitigations (forward `"$@"` in `deploy.sh`; WARN naming the absolute instructions-file path on overwrite) ARE required fixes, not waived. The remaining residual risk — a cloner running `./deploy.sh` overwrites their own `~/.claude/CLAUDE.md` with the repo's global rules — is surfaced to the maintainer in the delivery report for a product decision.
- **SEC-9 (INFO)** — TOCTOU between canonicalisation and delete. WAIVED: requires an attacker already writing with the user's own privileges; narrowed anyway by the SEC-1 fix (NOFOLLOW walk).
- **SEC-10 (INFO)** — loader walk follows symlinks, no cycle detection. WAIVED: pre-existing, self-inflicted DoS only. Follow-up candidate alongside SEC-1's primitive.
- **SEC-11 (INFO)** — `HOME_FOLDER: "~"` in `config.yml` is a literal path, not a home. WAIVED: pre-existing on main (commit 3406289), out of this delivery's scope. Surfaced in the delivery report.
- **CR-6, CR-10 (MINOR)** — stale README/`--working-dir`-only claim and stale `09_deployments/README.md` registry text. NOT waived — deferred by design to the scheduled documentation step (AC11), where documenter-project fixes both.
